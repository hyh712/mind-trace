## ✨ 核心特性

### 1. 🧭 探索大厅 (Topic Explorer)
- **拒绝空洞无趣的碎片化社交**：涵盖【自我探索】、【人生规划】、【伴侣与亲密】、【哲学与世界】四大板块与海量深度话题。
- **专题聚焦抽卡**：支持按细分主题胶囊精准抽题，支持手机端随时【➕ 自建专属题目】。

### 2. 📘 个人说明书 (Personal Manual)
- **15 大生活与认知维度 · 360 个深度自问**：从生理作息、情绪触发器到沟通禁忌与深层价值观。
- **快捷胶囊与自由自白**：选项点击即可填入，亦可自由详述，生成独一无二的《人类使用说明书》。

### 3. 📜 系统套卷与测评 (System Suites)
- **🧠 MBTI 16型人格专业测评**：28道经典性格动力学测评，单选即时打分，生成性格画像与潜能建议。
- **🎯 3小时人生方向全景梳理**：4大阶段、30道深度问卷，从现状诊断到落地行动清单。
- **💬 深度识人与自我对话问卷**：8大板块、57道灵魂拷问，读懂内心最真实的恐惧与渴望。

### 4. ⏳ 时光胶囊 (Time Capsule)
- 每一条话题打卡、每一次测评答卷自动按时间轴归档，随时回溯不同人生阶段的心智成长与心绪变迁。

### 5. 🧠 心智全景蓝图 & AI 测评 (Mental Blueprint)
- 动态汇总所有作答数据，可视化呈现心智维度分布。
- 支持接入大模型（阿里云百炼 / 通义千问 / DeepSeek / OpenAI / Gemini）进行全景心智诊断与行动建议。

## 🔒 隐私与数据安全 (Privacy First)

- **纯前端零服务端上报**：数据默认 100% 保存在用户设备本地浏览器的 `localStorage` 中。
- **API Key 绝对独立**：发给他人或公开部署时，不硬编码任何个人私有密钥；每位访客均在本地配置自己的 API Key，互不干扰、绝不泄露。
- **双轨同步机制**：支持导出完整 JSON 数据备份，亦可自选接入 Supabase 云端沙盒。

## 📱 手机端使用指南（添加到主屏幕体验媲美原生 App）

本项目完全基于响应式流体布局与 **PWA (Progressive Web App)** 规范设计，内置 Service Worker 离线强缓存，无需安装任何客户端：

### 🍎 iOS (iPhone / iPad - Safari 浏览器)
1. 在 Safari 中打开网站网址；
2. 点击浏览器底部中央的 **“分享”** 按钮（方框带向上箭头）；
3. 向下滑动并选择 **“添加到主屏幕” (Add to Home Screen)**；
4. 此时手机桌面即会生成专属的心岛应用图标，点击即可全屏无地址栏沉浸式启动！

### 🤖 Android (Chrome / Edge / 微信)
1. 在手机浏览器中打开网站网址；
2. 点击右上角菜单（三个点），选择 **“添加到桌面”** 或 **“安装应用”** 即可。
